States (DESIGN.md §Shared component states)

EmptyNo turns yet — send a message and the model that answers shows here.
LoadingCards in place; the Turns rows a skeleton while the transcript loads.
PartialCost not reported by Codex — showing tokens only.
RunningThe newest row keeps its until the turn's usage lands; tokens read "—".
ErrorA failed child keeps its row: and the adapter's one line, "Open in Agents".

What each row reads from

  • One row per assistant message carrying metadata.usage — usage lands once per turn on the last assistant message (agent.rs:345); the other messages of the turn share its inference
  • Runtime · model — message.metadata.inference (provider, requestedModel → resolvedModel); the arrow only when they differ
  • In · Out · Cache · Time · Cost — message.metadata.usage; Cache = cacheRead ÷ input, "—" when the seat reports none (unverified for claude-acp); Time = elapsedMs · timeToFirstTokenMs
  • Compaction — usage.isCompaction exists on the wire but nothing in the tree sets it; no row until it does
  • Child rows — one per DelegationUpdate: role (source) → runtime · model · status; tokens "—" until A2 fetches the child session
  • Settings — session.provider_name, model_config, the lever's stop, the ACP config options (thinking_effort), goose_mode. Ids and the permission gate show here in mono because Telemetry is a Diagnostics-tier surface — the DESIGN.md row says so
  • By model — group Turns by resolvedModel ?? requestedModel; Session line = tokenState.accumulated*
