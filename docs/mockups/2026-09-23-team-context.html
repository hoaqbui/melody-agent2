One editor: shared memories + everyone's own
  • Memories (top of the tree) is the team's shared bundle, ~/Melody/memories/, in OKF v0.2: one page per concept, drafts until you verify them
  • Below it, Melody and each companion: charter, memory, notes, journal — private to each
  • Plain markdown on disk; the editor renders tags, dates, trust and staleness as chips
Editing together
  • Editing: you change the text directly. Suggesting: changes show as tracked insert and delete marks to accept. Agents always suggest; only you edit directly
  • Presence: who's in the file — you editing, Melody suggesting, Tempo reading
  • Comments in the margin, answered here or in her chat
Memory-aware
  • / adds where a line came from (stated · observed · inferred), a safe-until, a link
  • Stale lines marked in amber; the footer counts lines against the cap
  • Cross-checks: the same fact in two memories is flagged, and saving offers to update the other
Guard rails
  • Charters are "you only": agents may only suggest there
  • Every save is one commit; History shows who changed what, with revert
  • A companion reads the new version at its next job, never mid-job
