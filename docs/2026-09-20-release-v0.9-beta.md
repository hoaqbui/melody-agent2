# melody-agent2 v0.9 beta — release note

Dated 2026-09-20. Tag `melody-v0.9-beta` on main; the app is `just make-ui`'s
`ui/desktop/out/Goose-darwin-arm64/Goose.app` from that tag (arm64, unsigned).

## What it is

A fork of goose 1.51.0 (`aaif-goose/goose`) as a Claude-first workspace: one window with
chat, Files, Editor, Changes, Terminal, Git, Browser, Markdown, Agents, Artifact and Review
panes; four runtime seats (Claude · Codex · Cursor · agy) with Direct and Orchestrate
modes; the Studio light theme and Charcoal Monokai dark; a phone web build over the
tailnet. Everything visible in `PRODUCT.md` §12's V0 and V0.5 tiers is built and walked.
